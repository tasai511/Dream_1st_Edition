# シンプル版バッジ一覧

## 基本方針

バッジは、以下の4カテゴリに整理する。

| カテゴリ | 評価するもの |
| --- | --- |
| スイング数 | たくさん振った |
| 練習日数 | 続けて練習した |
| 平均 | 今日の平均スコア・バット別の平均初突破 |
| ベスト | 今日のベストスコア・バット別のベスト初突破 |

複合条件、週間チャレンジ、月間チャレンジ、月間総合、バランス系は作らない。

## 実装メモ

- スイング数、練習日数、ベストは一度獲得したら獲得済みとして扱う。
- 平均スコア系は、スコアが下がって条件を満たさなくなったら獲得を外す。
- 初突破系はバットごとに判定する。同じ閾値でもバットが違えば別回として獲得する。
- ホームは今日の記録、チャレンジは進捗、バッジはコレクション、設定は既存機能を維持する。
