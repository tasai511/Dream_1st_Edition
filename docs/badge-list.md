# シンプル版バッジ一覧

## 基本方針

バッジは以下の3カテゴリに絞る。

| カテゴリ | 評価するもの |
| --- | --- |
| スイング数 | たくさん振った |
| 日数 | 続けて練習した |
| 成長 | スコアが伸びた・自己ベストに到達した |

複合条件、週間チャレンジ、月間チャレンジ、月間総合、バランス系は作らない。

## 実装メモ

- スイング数、日数、ベスト、自己ベスト到達は一度獲得したら獲得済みとして扱う。
- 平均スコア系は、スコアが下がって条件を満たさなくなったら獲得を外す。
- 平均スコアアップ系は、先週・先月に記録がない場合は未判定にする。条件を満たさなくなったら獲得を外す。
- 自己ベストが複数の閾値を同時に超えた場合は、該当するバッジをすべて獲得する。
- ホームは今日の記録、せいちょうは進捗、バッジはコレクション、設定は既存機能を維持する。
