# シンプル版バッジ一覧

## 基本方針

バッジは、チャレンジ画面の親カードに合わせて以下の4カテゴリに整理する。

| カテゴリ | 評価するもの |
| --- | --- |
| スイング数 | たくさん振った |
| 練習日数 | 続けて練習した |
| スコア | 今日のスコア・先週/先月比のスコアアップ |
| 過去最高 | 過去最高に到達した |

複合条件、週間チャレンジ、月間チャレンジ、月間総合、バランス系は作らない。

## 実装メモ

- スイング数、練習日数、ベスト、過去最高は一度獲得したら獲得済みとして扱う。
- 平均スコア系は、スコアが下がって条件を満たさなくなったら獲得を外す。
- スコアアップ系は、先週・先月に記録がない場合は未判定にする。条件を満たさなくなったら獲得を外す。
- ホームは今日の記録、チャレンジは進捗、バッジはコレクション、設定は既存機能を維持する。
